# Social Desk — PWA

Локальное приложение. Все данные хранятся в браузере (localStorage), наружу ничего не отправляется.

## Состав
- `index.html` — приложение (единый файл)
- `manifest.webmanifest` — манифест PWA
- `sw.js` — service worker (офлайн-режим)
- `icons/` — иконки 180/192/512 + maskable
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

## Публикация на GitHub Pages
1. Создайте репозиторий, например `social-desk`.
2. Загрузите все файлы этой папки в корень ветки `main`.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через 1–2 минуты откройте `https://<логин>.github.io/social-desk/`.

## Установка на iPhone
Safari → откройте URL → «Поделиться» → «На экран «Домой»».
Приложение запустится в полноэкранном режиме и работает офлайн.

## Установка на ПК
Chrome/Edge → значок установки в адресной строке.

## Ограничения
- Работа с реальной папкой на диске (File System Access API) доступна только в Chrome/Edge на десктопе и только по HTTPS. В Safari/iOS используйте экспорт/импорт JSON или ZIP.
- Данные не синхронизируются между устройствами автоматически: переносите файл экспорта JSON.
- Обновление версии: замените `index.html` и увеличьте номер `CACHE` в `sw.js`, иначе браузер отдаст старую копию из кэша.

## Локальная проверка
```
cd bundle
python3 -m http.server 8080
```
Откройте http://localhost:8080 (service worker работает на localhost и по HTTPS).
